# Nathália França — Portfolio Concept / Version 1

A responsive, working static website in English, designed around an editorial/minimalist matcha + blush identity. Zero build tools needed.

## How to open
Open `index.html` in a web browser. The page works locally; the Google Fonts import requires internet, with safe system-font fallbacks if offline.

## Publish to GitHub Pages
Upload the contents of this folder to the root of the portfolio repository and enable GitHub Pages from the main branch. Back up the existing site first. Alternatively use a new repository for preview.

## Included
- Responsive homepage, mobile navigation, animations and accessible case-study dialogs
- Three anonymized, editorial professional cases
- Method, professional journey, education, independent projects and contact
- Original CSS concept illustrations, no proprietary screenshots
- Working links to LinkedIn and email

## PRE-PUBLICATION REVIEW REQUIRED
1. Review English text and the exact boundaries of your employer/client confidentiality and approval policies. **This version does NOT name clients in cases or expose internal platform names, screenshots, code, endpoints or confidential figures.**
2. The "Selected Collaborations" section intentionally does NOT display client names/logos. If permitted, add an explicitly attributed text list of organizations you contributed to *through your employment*, subject to relevant brand permissions. Avoid unapproved implied endorsements.
3. The three independent project descriptions are editorial placeholders, not verified case-study details. Replace them with approved materials and verified links.
4. Verify the exact job titles/role timelines and current education status before publishing.
5. Validate that qualitative outcomes (human handoffs decreased, retention and evaluations improved) may be shared in anonymous form and that no language overstates causality.
6. If desired, add a real portrait (not generated without consent) and your current resume PDF link.
7. The site uses accessible conceptual illustrations; they are not representations of internal product UI.

## Editing
Everything is plain HTML/CSS/JavaScript. The theme colors are defined in `styles.css` under `:root`. Case-study contents are in `script.js` inside the `cases` object.
